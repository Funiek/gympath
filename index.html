Import własnego datasetu Gymów

Wgraj plik CSV, TSV, JSON albo GeoJSON zawierający nazwy i współrzędne Gymów. Możesz też wkleić dane jako tekst. Nie pobieramy automatycznie danych z Wayfarer ani z innych serwisów. Dane zostaną zapisane lokalnie na tym urządzeniu.

Zaimportujemy cały dataset; punkt startowy i promień wykorzystamy dopiero podczas planowania trasy. Zduplikowane Gymy zostaną pominięte, a wcześniejsza historia obrony zachowana.

Otwórz Wayfarer ↗ – sprawdź wybrane Gymy i przygotuj własną listę ich współrzędnych.

CSV: kolumny name,lat,lng (opcjonalnie popularity,status,type); status: unknown, friendly, full, enemy, mine, unavailable. Dane mieszane muszą mieć oznaczenie Gymu w polu type. Kopia zapasowa JSON zastępuje wszystkie dane; import datasetu dodaje Gymy bez kasowania historii.

Do obsługi na telefonie przez komputer: oba urządzenia połącz z tą samą siecią Wi-Fi i otwórz adres komputera. Instalacja PWA i automatyczna geolokalizacja zwykle wymagają HTTPS; przy zwykłym lokalnym HTTP wskaż start ręcznie.
